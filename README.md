# Shock Wave
## Overview
**Shock Wave** is a multi-player PVP game. It is programmed entirely in java with Maven.
It is still in development and is being made by a single developer: **Zonai Guardian**

## Play Testing
Anyone may play **Shock Wave** by following the setup steps below and making sure they have all requirements (also below).
### Installation
1. Download the latest .jar file from the versions folder.
2. Put it in a folder by itself (best for data saving)
3. (Optional) Create a shortcut to the .jar file and place it wherever you want
4. Double click the jar to start the game and have fun!

### Requirements
  - **The device that you run the game on must be a desktop-type device** as the game does not run on mobile.
  - **The device that will run the game must have java installed.** If you have ever run java code, Minecraft, or any other program that runs java then you're good to go. Otherwise, you may need to check if java (JDK or JRE) is installed and install it.
  - **An internet connection is required to play the game** as **Shock Wave** is for online play.
