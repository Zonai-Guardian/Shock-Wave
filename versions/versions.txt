Version number rules:
Increase by 1.0.0 when MAJORE gameplay feature or update is finished
Increase by 0.1.0 when regular feature or update is finished
Increase by 0.0.1 when small feature, update, hotfix, etc. is finished

Never save a new 1.0.0 or 0.1.0 version when the game does not run.
